## Conventions
- One folder per option: `opt-01-<short-name>/index.html` (self-contained, opens by double-click)
- Shared assets may import `../../public/w/core/*` (orb, lucide, data) via relative path
- `board.html` = review board listing every option with thumbnail, 1-line pitch, verdict
- Each option header: what the jury sees in 3 s · story beats with timings · fake vs real · build effort (h)
- Iterations: `opt-01-name/v2/` rather than overwriting, so Larry can compare
