# Pitch slides

Drop the final slide images here. `/app/slide.html?n=N` shows `slide-N.png` full-bleed when it exists, otherwise the blank placeholder.

| Step in the shell | File |
|---|---|
| 1 · Slide | `slide-1.png` |
| 2 · Slide | `slide-2.png` |
| 6 · Slide | `slide-3.png` |

- Size: 1600x940 (or 3200x1880 for sharp text on retina/beamer). Other ratios are cropped to fill (object-fit: cover).
- Export from PowerPoint/Keynote/Figma as PNG. No other config needed; reload the page.
