# Demo 2 logos

Optional official logo files for the apps on the Demo 2 map. Without them, each app shows its coloured monogram.

1. Save the file here as `<id>.svg` (preferred) or `.png` / `.jpg` / `.webp`.
2. Add the file name to `logos.json`, e.g. `["gmail.svg","stripe.svg"]`. Only listed files are loaded (avoids 404 noise).

Alternative: drag a logo file onto any app in the page (kept in that browser's localStorage).

Expected ids: gmail, outlook, whatsapp, attio, hubspot, stripe, chargebee, qbo (QuickBooks), xero, deel, remote, ramp, brex, spendesk, bills (Bills inbox), word (Word · PDF), excel, docusign, dropboxsign.
`vault` (Vaultly, fictional) ships with its own inline mark.
